    Conexión con GitHub

    Para que los cambios se vean en internet, el botón Publicar en GitHub guarda el catálogo directamente en su repositorio. Necesita un token (una llave) de GitHub, que se crea una sola vez:

    1. Entre a github.com/settings/personal-access-tokens/new.
    2. Nombre: distri-web. En Repository access elija Only select repositories y escoja el repositorio de la página.
    3. En Permissions → Contents elija Read and write. Pulse Generate token y copie la llave.

    La clave de entrada solo oculta este panel; la verdadera protección es el token: sin él nadie puede cambiar la página publicada.
